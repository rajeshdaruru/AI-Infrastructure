# AI-Infrastructure
A working record of my path into ML platform/infra engineering — GPU and distributed training fundamentals, model serving and inference, and the AI infra tooling around them, documented as I build it.

## Notebooks

- [sentiment-fine-tune-notebook.ipynb](sentiment-fine-tune-notebook.ipynb) — fine-tunes a Hugging Face `transformers` model for financial sentiment classification on the Financial PhraseBank dataset, saves the trained model in portable Hugging Face format, and reloads the saved model to run predictions.
